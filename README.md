# KBO LIVE Vercel v8

## 핵심 변경
- 5초 자동 갱신 시 전체 화면을 지우지 않습니다.
- 기존 경기 카드를 유지한 채 백그라운드에서 최신 데이터를 가져옵니다.
- 실제로 바뀐 경기 카드만 교체합니다.
- 상세 경기 화면도 데이터를 모두 받은 뒤 한 번에 교체하므로 빈 화면이 보이지 않습니다.
- API 오류가 발생해도 기존 화면을 유지합니다.
- 모바일 레이아웃은 v7과 동일하게 유지합니다.

## 배포
GitHub 저장소 루트에 `index.html`, `vercel.json`, `api/kbo.js`를 넣고 Vercel에서 해당 저장소를 Import하여 Deploy하세요.

## 이미지 출처
- 팀 로고: 네이버 스포츠 KBO 팀 엠블럼 URL을 우선 사용하고 실패 시 다음 스포츠 팀 로고로 fallback합니다.
- 선수 사진: 네이버 스포츠 선수 이미지 필드를 우선 사용하고, pcode 기반 네이버 스포츠 프로필 이미지를 시도합니다.
- 경기/기록 데이터는 네이버 스포츠가 KBO 공식 기록을 바탕으로 제공한다고 안내하고 있습니다.
